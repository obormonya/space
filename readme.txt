Timsort на C++

Учебная реализация алгоритма Timsort на C++ с использованием сортировки вставками для маленьких подмассивов и слияния для объединения блоков.

Структура проекта
Файл	Описание
main.cpp	Пример использования Timsort
timsort.h	Заголовочный файл с объявлением функции timsort
timsort.cpp	Реализация Timsort и вспомогательных функций
Использование

Пример:

#include <iostream>
#include <vector>
#include "timsort.h"

int main() {
    std::vector<int> arr = {5, 21, 7, 23, 19, 4, 12, 9, 1, 3};
    timsort(arr);

    for (int x : arr) std::cout << x << " ";
}


Вывод:

1 3 4 5 7 9 12 19 21 23

Компиляция
g++ main.cpp timsort.cpp -o timsort_example -std=c++17
./timsort_example

Особенности

Размер маленьких блоков (RUN) = 32;

Учебная, понятная реализация, идеально подходит для изучения алгоритма;

Использует сортировку вставками для маленьких подмассивов и слияние для больших.
